# 已转存 mmbiz 图（可选格）

素材库页面本身通常**没有**「复制图片地址」。不要在素材库里右键缩略图。按下面取你自己的地址；取不到就跳过，记「未测」。

1. 公众号后台 → 草稿箱 → 新建图文 → 从素材库插入一张**你自己的**图
2. 在编辑器里点中这张图，右键 →「在新标签页中打开图片」（没有这一项就右键 → 检查，复制 `img` 的 `src` 或 `data-src`）
3. 地址栏里应是 `https://mmbiz.qpic.cn/...` 或 `https://mmbiz.qlogo.cn/...`。整段复制，换成下面括号里的地址
4. 不要用别人文章里的 mmbiz 链接，会防盗链

![已转存 mmbiz 图](https://mmbiz.qpic.cn/REPLACE_WITH_YOUR_MMBIZ_URL)

对照：复制按钮旁**不应**再为这一张报「不是公众号地址」。后台和手机预览都应直接看见，地址仍是 mmbiz。
