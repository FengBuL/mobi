# 压图角标（事实 B）

预览里「前 / 后」应压在图上，并打标「角标会落到图下」。贴进公众号后角标应跑到图下方，图本身还在。

- 预览有「角标会落到图下」

- 与打标一致记「构图变化但已打标」；角标或图消失记「丢失」或「未预期差异」
