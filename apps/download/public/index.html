墨笔 打开网页版

下载桌面端

网页版打开即用。想装到电脑上，从这里下安装包。当前桌面包是 v2.3.1。

macOS

Apple 芯片选 arm64，Intel 选 x64。第一次打开会被拦，到「隐私与安全性」里点「仍要打开」。

Apple 芯片 Intel

Windows

64 位安装包。若弹出 SmartScreen，选「更多信息 → 仍要运行」。

下载 Windows

Linux

不出 Linux 安装包，请直接用网页版。

打开网页版

安装包没有买证书做公证。macOS 15 及以上被拦后，打开「系统设置 → 隐私与安全性」，往下翻点「仍要打开」。Windows 若弹出 SmartScreen，选「更多信息 → 仍要运行」。
