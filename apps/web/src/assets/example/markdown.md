# 写完的稿，怎样变成能贴出去的样子

这是一篇示例成稿。打开编辑器就能看见成品：左边是源文，右边是预览。不用先填工作区问卷，也不用先上语法课。

## 先看成稿，再动手改

标题、导语、小节都已经排好。你改几个字，预览会跟着变。主题可以稍后换，先把这篇当成能贴出去的样子看一遍。
